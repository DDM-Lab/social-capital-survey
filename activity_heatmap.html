Hunt Library activity map

Each mark represents a selected grid cell. Circle area or cell opacity increases with the number of visits selecting that cell for that activity. Hover for counts. Select one activity for an unobstructed heatmap.

Colors identify activities; overlapping marks can obscure one another. Counts represent visits, including repeat visitors on different days. Cells are not exact physical points, and counts do not measure dwell time or occupancy. Blank areas mean no recorded selections in this subset. Time periods use voucher categories; weekdays use survey start dates. Peak labels identify the most selected cell for each visible activity, choosing the top-left cell in a tie. The intensity scale is shared across visible activities and recalculated when filters change.
